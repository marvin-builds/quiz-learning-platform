# Quiz learning platform

A free, non-commercial learning platform: multiple-choice quizzes in
categories, played anonymously or with an account, and managed by admins in
the same app. It runs on the web, Android and iOS (Expo) with Supabase as the
backend, and is built test-first with Claude Code as the main implementer.
Start with [`CLAUDE.md`](CLAUDE.md) for the commands, layout and rules, and
[`docs/plan/`](docs/plan/) for the scope, architecture and implementation plan.
